# Phrases to cut or replace

Substitutions assume scientific prose. The right fix is usually deletion: if removing the phrase loses no information, it was filler.

## Throat-clearing openers

| Cut | Replace with |
|---|---|
| Here's the thing: | (delete, state the claim) |
| Let's break this down. | (delete) |
| Before we dive in, | (delete) |
| It is important to note that X | X |
| It is worth noting that X | X |
| It should be emphasized that X | X |
| Interestingly, X | X, or state why it is interesting |
| Notably, X | X, or name what distinguishes it |
| As we all know, X | (delete, or cite X) |
| Needless to say, X | (delete) |

## Filler transitions

| Cut | Replace with |
|---|---|
| That being said, | However, or (delete) |
| At the end of the day, | (delete) |
| When it comes to X, | For X, or (delete) |
| In today's rapidly evolving landscape, | (delete) |
| Moving forward, / Going forward, | (delete, or name the timeframe) |
| Furthermore, Moreover, Additionally (stacked) | Keep at most one per paragraph |
| In other words, X | Say it once, correctly |

## Emphasis crutches

Delete all of these outright: Let that sink in. And that matters. Make no mistake. Here's the kicker. Full stop. That's the whole point. Nothing more, nothing less.

## Business jargon in technical prose

| Cut | Replace with |
|---|---|
| leverage X | use X |
| navigate the landscape/complexities of X | (name the specific difficulty) |
| the X ecosystem | X tools, X software, X community |
| unlock the potential of X | (state what X enables, concretely) |
| harness the power of X | use X |
| game-changing | (state the size of the change) |
| seamless / seamlessly | (delete, or say what integration was required) |
| robust (as praise) | (give the stability metric) |
| holistic | (name what is included) |
| synergy / synergistic | (unless you mean the pharmacological term, delete) |
| best practices | (name the practice and cite it) |
| deep dive | (delete) |
| actionable insights | (state the action) |

## AI vocabulary tells

Delete or replace on sight: delve, delving, tapestry, realm, myriad, plethora, treasure trove, testament to, beacon, labyrinthine, cornerstone, ever-evolving, ever-changing, cutting-edge, state-of-the-art (as an adjective for your own work; fine when naming a benchmark comparison), pivotal, paramount, crucial (usually replaceable by "necessary" or nothing), meticulous, nuanced, intricate, multifaceted, underscore, showcase, elevate, foster, embark, unravel, illuminate, resonate, transformative, unparalleled, unprecedented.

Note the exceptions: "crucial" and "pivotal" have technical uses (pivotal trial). "State of the art" is a legitimate noun phrase in a benchmark table. The tell is decorative use.

## Empty importance verbs

| Cut | Replace with |
|---|---|
| X underscores the importance of Y | (say what X implies for Y) |
| X highlights the need for Y | (say what fails without Y) |
| X sheds light on Y | X shows that Y..., or X constrains Y |
| X serves as a foundation for Y | X is used by Y, or Y builds on X |
| X plays a crucial role in Y | (name the mechanism: X phosphorylates Y) |
| The importance of X cannot be overstated | (delete, then quantify X's effect) |
| X stands as a testament to Y | (delete) |

## Vague attribution

| Cut | Replace with |
|---|---|
| Researchers have shown that X | Author et al. (year) reported X |
| Studies suggest X | (cite two or three, or drop the claim) |
| It has long been recognized that X | (cite the earliest relevant work) |
| It is widely accepted that X | (cite a review) |
| Recent work has demonstrated X | Author et al. (year) demonstrated X |
| Experts argue X | (name the expert) |

If you cannot name the source, you do not have one. Say what you observed instead.

## Vague declaratives

| Cut | Replace with |
|---|---|
| The implications are significant. | (name the implication and who it affects) |
| The reasons are structural. | (name the reason) |
| This has important implications for the field. | (name the decision that changes) |
| Results were promising. | (give the number) |
| Performance was substantially better. | (give the delta and the interval) |
| There is much work to be done. | (name the next experiment) |
| Future work will explore X. | (say what X would test and why it is unresolved) |

## Hedge stacks

Keep exactly one hedge, matched to your evidence.

| Cut | Replace with |
|---|---|
| may potentially indicate | may indicate |
| could possibly suggest | suggests, or may indicate |
| appears to be somewhat associated with | is associated with (give the estimate) |
| we believe it is likely that X | X is consistent with our data |
| it is tempting to speculate that X | we cannot test X here (state why) |
| relatively / fairly / rather + adjective | (delete the qualifier or quantify it) |

## Adverbs to cut

Cut when they carry no measurement: quietly, effortlessly, seamlessly, deftly, elegantly, remarkably, strikingly, dramatically, vastly, incredibly, extremely, highly, truly, really, quite, arguably, notably, interestingly, importantly, fundamentally.

Keep when they are the technical term: statistically (significantly), monotonically, asymptotically, exponentially, linearly, orthogonally. "Significantly" is only allowed when a test backs it; otherwise write "substantially" with a number.

## Meta-commentary

| Cut | Replace with |
|---|---|
| In this section, we will explore X | (just write about X) |
| The rest of this paper is organized as follows | (keep only if the venue requires it) |
| What follows is a discussion of X | (discuss X) |
| As mentioned above, X | (delete, or cross-reference a section number) |
| To reiterate, X | (delete) |
| In summary, / In conclusion, | (delete; a Conclusion section is already labelled) |

## Reviewer-response specific

| Cut | Replace with |
|---|---|
| We thank the reviewer for this insightful comment. | Use once in the opening, then answer points directly |
| We appreciate the opportunity to clarify. | (delete) |
| We have carefully considered this point. | (state what changed) |
| As the reviewer correctly notes, | (delete, then agree or disagree) |
| We respectfully disagree. | We disagree, because (reason) |
| This has been addressed in the revised manuscript. | Revised: p. 7, lines 12-18 (quote the change) |
