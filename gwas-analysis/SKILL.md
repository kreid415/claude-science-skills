# GWAS with plink2 and regenie

Helpers (`kernel.py`) are loaded with this skill: `run_cmd`, `plink2_qc_cmds`, `sample_outliers`, `run_qc`, `make_covar_file`, `plink2_glm_cmd`, `plink2_clump_cmd`, `regenie_cmds`, `load_sumstats`, `genomic_inflation`, `manhattan_plot`, `qq_plot`. Commands are returned as strings so you can read, edit and log them before `run_cmd`.

## When to use / not use
- Use: association scan of a quantitative or binary trait on array or imputed-dosage genotypes (VCF, bed/bim/fam, pgen), including QC and covariate construction.
- Variant calling from reads: use the variant-calling skill. Functional annotation of lead variants (VEP/ANNOVAR, ClinVar, gnomAD): hand off to `variant-annotation`. Public reference genotypes (1000 Genomes): `onekgpd`. Sample-size / power: `statistical-power`.
- Rare-variant burden/SKAT masks (regenie `--anno-file/--set-list/--mask-def`) are out of scope here.

## Environment
- `genomics` conda env has plink2. regenie is in a separate env (bioconda regenie pins an older boost that conflicts with current htslib): pass `regenie_bin='/path/to/envs/regenie/bin/regenie'`. Create it with `manage_environments(mode="create", name="regenie", packages=["regenie"], channels=["bioconda","conda-forge"])`.
- In sandboxed containers regenie can abort with `OMP: Error #179 pthread_setaffinity_np`; `regenie_cmds` prefixes `KMP_AFFINITY=disabled` (observed to fix it).

## Workflow
1. **Inputs / build.** Decide the reference build first (GRCh38 vs GRCh37) and record it. `--split-par b38|b37` separates chrX PAR (needed before `--check-sex`); regenie `--par-region` defaults to hg38. plink2 recognises `chr1`/`1`/`X`/`chrX` on input and writes `1`,`X` by default (`--output-chr chrM` to emit `chr` prefixes). VCF import needs `--double-id` (FID=IID); biallelic only (`--max-alleles 2`); `--set-all-var-ids '@:#:$r:$a'` gives unique chr:pos:ref:alt IDs (quote `$` in bash). Non-unique variant IDs make `--indep-pairwise` error out (plink2 docs); `--clump` splits multiallelics and needs an A1 column.
2. **QC.** `cmds = plink2_qc_cmds(src, out, src_type='vcf'|'bed'|'pgen', sex_file=..., pheno=..., cc_col='BT')`; `info = run_qc(cmds, out)`. Steps: import -> (controls-only HWE) -> filter (`--mind 0.02 --geno 0.02 --maf 0.01 --hwe 1e-6 midp`) -> `--indep-pairwise` -> `--het`, `--check-sex`, `--king-cutoff` on pruned variants -> `sample_outliers` (union of KING exclusions, |F| > 3 SD heterozygosity outliers, hard sex mismatches; writes `{out}.remove.txt`) -> `{out}.final` -> `--pca`. Check each plink2 `.log` for counts removed; record them.
   - `--mind` is applied before the variant filters in the same run (plink2 order of operations), so sample missingness is computed on unfiltered variants. For messy data run a loose `--geno 0.1`, then `--mind`, then the strict `--geno`.
   - HWE: plink2 has no case/control special-casing; use `--keep-if <pheno> == control` (done by `cc_col`). `--hwe` is founders-only by default and errors if the threshold looks too strict for the sample size unless `k` is given (`--hwe p k midp`; k=0.001 suggested for large samples, p~1e-5 for small); `keep-fewhet` retains Wahlund-effect (stratification) variants.
   - KING thresholds (kinship scale: duplicate = 0.5, first-degree ~0.25, second ~0.125, third ~0.0625). `--king-cutoff t` drops one of each pair with kinship > t. 0.354 (2^-1.5) = duplicates/MZ only; **0.177 (2^-2.5) = also removes first-degree relatives; 0.0884 (2^-3.5) = also removes second-degree; 0.0442 = third-degree.** Estimates are noisy with few SNPs: on the simulated 1,000 samples x 1,468 pruned SNPs, 0.0884 excluded 13 samples (4 true duplicates + 9 unrelated), 0.177 excluded 4 (the 4 duplicates). Use genome-wide-scale pruned autosomal SNPs (>=100k) for real data; KING-robust underestimates kinship for parents from very different populations.
   - `--check-sex` has **no default thresholds**; the helper passes `max-female-xf=0.2 min-male-xf=0.8`. Female chrX F is widely dispersed: 2/499 simulated females fell between thresholds (SNPSEX=NA); these are reported (`sex_ambiguous`), not removed. Needs `--split-par` and approximate HW/LE variants.
   - Het outliers: F from `--het` on pruned variants; very unbalanced ancestry mixes need per-ancestry runs.
3. **Covariates.** `--pca 10` on LD-pruned, relatedness-pruned QC variants (`approx` when N > 5000). `make_covar_file(pheno, f'{out}.pca.eigenvec', 'covar.tsv', 10)` merges PCs with sex/age (header `FID IID ...`, valid for both tools). Inspect PC plots for batch/outlier structure before use.
4. **Association.**
   - plink2: `run_cmd(plink2_glm_cmd(f'{out}.final','covar.tsv','QT','covar.tsv','SEX AGE PC1-PC10', out_prefix, binary=False))`. Uses `--covar-variance-standardize`, `--mac 20` (plink2 advises it before --glm), `omit-ref` (A1 = ALT; the default A1 is the minor allele), `hide-covar`. Binary: Firth only when logistic fails (`firth-fallback`; files `.glm.logistic.hybrid`); `firth` forces it. **If SEX is in the covariate file and chrX is present, plink2 errors unless `no-x-sex` is set** (default on in the helper). Binary phenotype coding in plink2 files: 1=control, 2=case. `--glm` does not model relatedness: prune relatives or use regenie.
   - regenie: `r = regenie_cmds(f'{out}.final','covar.tsv','BT','covar.tsv','SEX,AGE,PC1,...',out_prefix, binary=True, extract_step1=f'{out}.prune.prune.in', bsize1=100, regenie_bin=...)`; run `r['step1']` then `r['step2']` from the same working directory (`_pred.list` stores the loco paths as given). Step 1 fits the whole-genome ridge model on a pruned/high-quality set (docs: several hundred thousand common array markers; UK Biobank recipe uses blocks of 1000 in step 1, 200 in step 2); `--bsize` must be well below the number of step-1 variants, and low-variance SNPs make step 1 error, so apply maf/mac/geno QC first. Binary traits: `--bt` expects 0/1, the helper adds `--cc12` for 1/2 coding; step 2 uses `--firth --approx` (Firth LRT fallback below `--pThresh`, default 0.05). Output `{out}_s2_{pheno}.regenie`: CHROM GENPOS ID ALLELE0 ALLELE1 A1FREQ N TEST BETA SE CHISQ LOG10P EXTRA; ALLELE1 is the tested (effect) allele (ALT for pgen; for bed the last bim allele is the reference unless `--ref-first`); chrX is reported as 23.
5. **Post-processing.** `d = load_sumstats(path, tool='plink2'|'regenie')` -> CHR(int, X=23), POS, ID, A1, BETA, SE, P, LOG10P (+OR, A1_FREQ). `genomic_inflation(d.P)` = median chi2(1 df)/0.4549. Genome-wide significance 5e-8 (for a panel of only a few thousand SNPs also report the Bonferroni level 0.05/M). `fig = manhattan_plot(d, highlight=ids)`, `fig = qq_plot(d.P)`; save with `fig.savefig(...)`. Clumping: `run_cmd(plink2_clump_cmd(f'{out}.final', glm_file, out_prefix))` -> `{out_prefix}.clumps` (index variants chosen greedily by p <= `--clump-p1`; members within `--clump-kb` and r2 > `--clump-r2`; by default only `TEST==ADD` rows are read; r2 is haplotype-based unless `--clump-unphased`). Lead variants (clump index rows: CHR, POS, ID, A1, REF/ALT from the .pvar, build) go to `variant-annotation`.
6. **Provenance.** Record: reference build; `plink2 --version` (validated on v2.0.0-a.6.9LM, 29 Jan 2025) and `regenie --version` (v4.1.3); exact command strings; thresholds; variant/sample counts after each step; phenotype coding; PC count; seeds (`--pca approx` and simulations are randomised).

## Caveats
- Case-control imbalance: unadjusted logistic tests are miscalibrated for rare variants; use Firth (`firth-fallback`/`--firth --approx`), filter low MAC, and do not read OR/P literally when expected minor-allele counts in cases are < ~0.5 (plink2 docs).
- Relatedness inflates statistics under plain `--glm`; PCs do not fix family structure. Remove relatives or use regenie/mixed models.
- Stratification: PCs from pruned, relatedness-filtered variants; λGC > 1 may be polygenicity rather than confounding (LD-score regression intercept distinguishes them); do not divide statistics by λGC without checking.
- Winner's curse: effect sizes of genome-wide-significant lead variants are upward-biased in the discovery sample; replicate or use a bias-corrected estimate before quoting effects.
- Multiple testing: 5e-8 assumes ~1M independent common tests; report the threshold used.
- Long-range LD regions (build-specific, e.g. MHC) distort PCA/het; exclude them from the pruned set when known for the build.
- Allele alignment: compare tools / cohorts on (ID, A1); plink2's minor-allele default A1 is dataset-dependent.

## Validation on simulated data (seed 42; `scripts/simulate_gwas.py`, bundled)
1,000 samples, 5,000 autosomal SNPs (chr1-10, LD blocks of 10) + 200 chrX SNPs, 4 duplicates, 3 planted causal SNPs. After QC (995 samples, 5,200 variants), lambda_GC / planted SNPs with P<5e-8: plink2 QT 0.988 / 3 of 3; regenie QT 0.971 / 3 of 3; plink2 BT 0.982 / 3 of 3; regenie BT (--firth --approx) 1.038 / 3 of 3. plink2 and regenie QT effect-size correlation 0.97; A1 identical for all 5,200 variants. `--clump` formed 3 clumps, indices = the 3 planted SNPs.
